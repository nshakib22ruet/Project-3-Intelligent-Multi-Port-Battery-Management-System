Project 3

ESP32-Based Intelligent Multi-Port Battery Management System

Md. Najmus Shakib

EEE, Rajshahi University of Engineering & Technology (RUET)

Overview

An ESP32-based system that charges and supervises multiple batteries at the same time. It measures voltage, current and temperature on each charging path, switches the paths through relays in manual or automatic mode, and shows the live data on a dashboard. A machine learning model can use the same data to judge battery condition and spot possible degradation.

About the Project

The system takes 220 V AC mains as its power source. A step-down transformer lowers the voltage, a bridge rectifier converts it to DC, and a filter capacitor smooths the result. An L7805CV regulator then supplies a steady 5 V to the relay module, while an LM2596 buck converter adjusts the charging voltage for Battery Port 2.

The ESP32 is the central controller. It operates the relay channels that connect or disconnect each charging path, following the manual or automatic operating mode. INA219 sensors measure the voltage and current of the connected charging paths, and two DS18B20 sensors measure battery temperature. The ESP32 collects all of these readings continuously in real time.

From the readings, the software estimates battery voltage percentage, charging current, internal resistance (when valid measurement conditions are available) and temperature status. It then compares voltage, current variation, estimated resistance and temperature to identify possible battery degradation. The same data can be passed to a machine learning model that classifies battery condition and supports health assessment.

A dashboard displays real-time battery information, charging status, temperature, estimated health and relay status, with Bluetooth communication between the ESP32 and the monitoring interface where implemented. Together, the sensor measurements, programmed control logic and machine learning predictions manage the multiple charging ports, raise protection alerts and improve charging supervision.
