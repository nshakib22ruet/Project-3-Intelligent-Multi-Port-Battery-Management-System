Abstract

This project presents an ESP32-based intelligent multi-port battery management system that charges and supervises several batteries at once. The ESP32 reads voltage, current and temperature from INA219 and DS18B20 sensors, switches each charging path through relays in manual or automatic mode, and sends the data to a dashboard over Bluetooth. From these readings the software estimates battery percentage, charging current, internal resistance and temperature status, and a machine learning model can classify battery condition to support health assessment and early detection of degradation.

Required Components

  • 220 V AC mains supply
  • Step-down transformer
  • Bridge rectifier
  • Filter capacitor
  • L7805CV 5 V regulator
  • LM2596 buck converter
  • ESP32 controller
  • Relay module
  • INA219 voltage/current sensors
  • DS18B20 temperature sensors (2)
  • Batteries under charge

Working Principle

  1. AC Power Input: The system receives 220 V AC mains electricity as its primary power source.
  2. Voltage Transformation: A step-down transformer reduces the high AC mains voltage to a lower AC voltage suitable for the system.
  3. AC-to-DC Conversion: A bridge rectifier converts the transformer's AC output into DC voltage.
  4. DC Filtering: A filter capacitor smooths the rectified DC voltage to provide a more stable power supply.
  5. Voltage Regulation: An L7805CV regulator provides regulated 5 V for the relay module, while an LM2596 buck converter adjusts the charging voltage for Battery Port 2.
  6. ESP32 Controller: The ESP32 acts as the central controller, managing sensor readings, relay operations, battery monitoring and communication.
  7. Relay-Based Control: The ESP32 controls individual relay channels to connect or disconnect the charging paths according to manual or automatic operating modes.
  8. Voltage and Current Monitoring: INA219 sensors measure the voltage and current of the connected battery charging paths.
  9. Temperature Monitoring: Two DS18B20 temperature sensors measure battery temperature to monitor thermal conditions during charging.
  10. Real-Time Data Collection: The ESP32 continuously collects voltage, current and temperature measurements from the sensors.
  11. Battery Parameter Calculation: The software processes sensor readings to estimate battery voltage percentage, charging current, internal resistance (when valid measurement conditions are available) and temperature status.
  12. Battery Condition Assessment: The system evaluates battery behaviour using voltage, current variation, estimated resistance and temperature to identify possible battery degradation.
  13. Machine Learning Analysis: The collected battery data can be processed by a machine learning model to classify battery conditions and support intelligent battery health assessment.
  14. User Interface and Communication: A dashboard displays real-time battery information, charging status, temperature, estimated health and relay status, with Bluetooth communication between the ESP32 and the monitoring interface where implemented.
  15. Intelligent Battery Management: Finally, the system uses sensor measurements, programmed control logic and machine learning predictions to manage multiple battery charging ports, provide protection alerts and improve charging supervision.
Overall working principle: The system integrates power conversion, ESP32-based control, sensor monitoring, relay switching, software-based battery analysis and machine learning to develop an intelligent multi-port battery management platform.
